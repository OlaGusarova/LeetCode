# LeetCode Solutions - TypeScript

Мои решения задач LeetCode на TypeScript с типизацией и тестами.

## Структура

- `solutions/` - все решения по задачам
- Каждая задача в отдельной папке с номером и названием

# Установка зависимостей
npm install

# Создание новой задачи
npm run new [id] [name] [difficulty]

# Запуск тестов
npm run test

# Проверка типов
npm run type-check
